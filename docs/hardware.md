# 多相交错 Boost 硬件说明文档

> ⚠️ **本文档与当前 BSP 驱动代码不匹配**
>
> 本文档描述的是**三相交错 Boost 升压电源板**的硬件，而当前实例 `examples/GD32F303_DevBoard` 的 BSP 驱动实际适配的是**另一套硬件**（电机控制板）。PWM/ADC/USART/LED 管脚定义均不一致。
>
> **开发时以代码中各模块 `.h` 文件定义的管脚宏为准**，待硬件平台确认后需统一修正本文档或驱动代码。
> 详细对比见 `framework-dev-guide.md` 第 1.4 节。

## 1. 系统概述

本硬件为三相交错 Boost 升压电源，采用 GD32F103C8T6 / STM32F103C8T6
作为主控制器。

主要功能：

-   三相交错 PWM 控制
-   三相电感电流采样
-   输出电压采样
-   输出电流采样
-   USB 串口通信
-   SWD 调试接口

------------------------------------------------------------------------

## 2. 主控 MCU

  项目       参数
  ---------- ------------------------------
  MCU        GD32F303CCT6
  内核       ARM Cortex-M3
  工作电压   3.3V
  时钟       外部 8MHz 晶振

------------------------------------------------------------------------

## 3. 功率级

### 3.1 三相交错 Boost

功率级由三组独立 Boost 单元组成：

  相位   电感   上管 PWM   下管 PWM
  ------ ------ ---------- ----------
  A相    L2     PWMA       PWMAN
  B相    L3     PWMB       PWMBN
  C相    L4     PWMC       PWMCN

功率 MOS：

-   Q1/Q2：A 相功率管
-   Q3/Q4：B 相功率管
-   Q5/Q6：C 相功率管

------------------------------------------------------------------------

## 4. PWM接口

PWM由 MCU TIM1\TIM2\TIM3 定时器的CH1\CH2分别输出。

  信号    MCU引脚   功能
  ------- --------- ---------
  PWMA    PB6       A相上管
  PWMAN   PB7       A相下管
  PWMB    PB5       B相上管
  PWMBN   PB4       B相下管
  PWMC    PB3       C相上管
  PWMCN   PA15      C相下管


驱动器：

-   U8：A相驱动
-   U9：B相驱动
-   U10：C相驱动

------------------------------------------------------------------------

## 5. 电流采样

每相电感电流采用采样电阻 + 运算放大器进行检测。

  信号   MCU引脚   ADC通道
  ------ --------- ----------
  ADCA   PA0       ADCx_IN0
  ADCB   PA1       ADCx_IN1
  ADCC   PA2       ADCx_IN2

对应检测电路：

-   A相：R38（5mΩ）
-   B相：R35（5mΩ）
-   C相：R32（5mΩ）

------------------------------------------------------------------------

## 6. 电压、电流检测

### 输出电压检测

    信号     MCU引脚   ADC通道
  -------- --------- ----------
  ADC_UOUT    PA3     ADCx_IN3

用于检测 Boost 输出母线电压。

### 输出电流检测

    信号     MCU引脚   ADC通道
  -------- --------- ----------
  ADC_IOUT    PA4     ADCx_IN4

用于检测负载输出电流。

### 输入电压检测
    信号     MCU引脚   ADC通道
  -------- --------- ----------
  ADC_POW    PA5     ADCx_IN5

------------------------------------------------------------------------

## 7. 通信接口

### USB转串口

芯片：

-   CH340N

接口：

  信号        MCU引脚
  ----------- ---------
  USART0_TX   PA9
  USART0_RX   PA10

### I2C 接口

接口：

  信号    MCU引脚    功能
  ------- --------- ----------
  I2C0_SCL    PB6       I2C0 时钟线
  I2C0_SDA    PB7       I2C0 数据线

扩展接口：

  I2C0 挂载设备：

  -   AS5600（磁编码器，7位地址 0x36）

------------------------------------------------------------------------

### 扩展串口

  信号        MCU引脚
  ----------- ---------
  USART2_TX   PB10
  USART2_RX   PB11

------------------------------------------------------------------------

## 8. 调试接口

SWD：

  信号    MCU引脚
  ------- ---------
  SWDIO   PA13
  SWCLK   PA14

------------------------------------------------------------------------

## 9. 用户接口

### 按键

  信号   MCU引脚
  ------ ---------
  KEY1   PA8
  KEY2   PB15
  KEY3   PB14
  KEY4   PB13

### LED

  信号    MCU引脚
  ------- ---------
  LED_R   PC15
  LED_G   PC14
  LED_B   PC13

------------------------------------------------------------------------

## 10. 电源系统

输入：

-   VBAT / VIN

电源转换：

-   +12V：功率驱动部分
-   +5V：辅助供电
-   +3.3V：MCU及逻辑电路

3.3V稳压：

-   ME6211C33

## 11. 硬件信号汇总

  类型       信号
  ---------- ----------------------------------
  PWM        PWMA/PWMAN/PWMB/PWMBN/PWMC/PWMCN
  相电流     ADCA/ADCB/ADCC
  输出检测   ADC_UOUT/ADC_IOUT
  电源检测   ADC_POW
  通信       USART0/USART2
  调试       SWD
  用户输入   KEY1\~KEY4
  状态显示   LED_R/G/B
